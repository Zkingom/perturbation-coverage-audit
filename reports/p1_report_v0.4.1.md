# P1 报告（方案 v0.4.1）

日期：2026-10-03。范围：均值、linear-PCA、linear-GO（每次划分选出的 d，以及 d = 2 复现版），3 次 TSS 组随机划分，种子 20261001–20261003。本报告只针对 P1 的流程验证。分箱覆盖率只有 3 次划分，不做推断；G1 尚未开始。

## 结论

1. **全部泄漏 assert、两个 canary 和三项自检都通过了；Gram 与 SVD 在数值上一致。**
2. **在验证集上，线性模型相对均值模型的改进很小，只有 3–4%。** linear-GO 在 3 次划分中都选中了 d = 20，正好是网格的上界，而且验证误差随 d 增大仍在下降。
3. **linear-GO 的验证改进是在选 d 的同一个验证集上计算的，偏乐观。** 无偏的比较应该看校准集给出的 q̂：在主组合（S1_k50，α = 0.1）上，q̂ 的平均值分别为：
   - 均值：6.766
   - linear-PCA：6.545
   - linear-GO：6.548
   - linear-GO d = 2：6.742

   也就是说，在相同的覆盖保证下，两个线性模型给出的区间半径比均值模型约窄 3%；linear-GO 与 linear-PCA 实质上相同。

## 数据

- 单细胞文件：310,385 个细胞 × 8,563 个基因；X 为稠密 float32 矩阵。
- L 取 `obs.UMI_count`。这 8,563 个基因平均覆盖每个细胞 98.6% 的 UMI。
- pseudobulk 共 2,273 行：2,176 个扰动行，加 97 个有细胞的 non-targeting 行；bulk 文件中另有 12 个 non-targeting 行没有细胞。
- 训练和评估用到的 2,043 个单元，单细胞文件里的细胞数与 bulk 文件的 `num_cells_filtered` 完全一致，比例为 1.000。

## 泄漏检查（3 次划分全部通过）

- **L1 / L2**：每次划分都构成 E 的一个划分，没有重复或遗漏；每个 TSS 组只出现在一个 fold 中；训练池与 val、cal、test 之间，单元不重叠，TSS 组也不重叠。
- **W 的拟合列**：两个线性模型拟合 W 用到的列，都只来自训练池。
- **参照行**：参照行全部来自训练池，且细胞数都 ≥ 30。
- **v0.4.1 新增**：均值模型的预测等于 μ_tr。
- **canary A**：把 cal 和 test 换成随机数后，参照量、全部候选模型的预测、三种距离和选出的 d 都没有变化。
- **canary B**：把 val 换成随机数后，参照量、全部候选模型的预测和三种距离都没有变化。
- **L10**：3 个划分文件 `splits/v0.4/A_000–A_002.json` 写入后设为只读，尝试写入会被拒绝。

## 验证集误差：S1(k=50) 的平均值，及相对均值模型的改进

相对改进 = 1 − 误差_模型 / 误差_均值；正值表示优于均值模型。

| 模型 | 划分 0 | 划分 1 | 划分 2 | 3 次平均 |
|---|---|---|---|---|
| linear-PCA | +2.50% | +4.67% | +2.01% | +3.06% |
| linear-GO d = 2（复现版） | +0.38% | +0.55% | +0.55% | +0.49% |
| linear-GO d = 5 | +1.00% | +1.12% | +1.22% | +1.11% |
| linear-GO d = 10 | +2.96% | +3.58% | +2.77% | +3.10% |
| linear-GO d = 20（**每次都被选中**） | +3.69% | +4.45% | +3.30% | +3.82% |

均值模型自身的验证误差分别为 4.440、4.426、4.180。

读这张表时，有三点需要注意：
- **选中的 d 落在网格边界。** 验证误差从 d = 10 到 d = 20 仍在下降，说明 {2, 5, 10, 20} 这个网格可能偏小。是否扩大网格（例如加入 30、50）属于方案改动，需要你决定。
- **linear-GO 的改进有选择偏差。** 被选中模型在验证集上的改进，是在同一个验证集上挑出来的，因此偏乐观。d = 2 复现版不经调参，只比均值好 0.5%。
- **只有 3 次划分，不能比较模型之间的差异。** linear-PCA 与 linear-GO 之间的差值小于划分间的波动，3 次划分不足以判断孰优孰劣。

## 三项自检

| 自检 | 结果 | 判定 |
|---|---|---|
| (i) 边际覆盖：144 个组合中落在 Beta-二项 95% 参照带外的个数 | 1 个，二项 P(≥1) = 0.999 | 通过 |
| (ii) 阳性对照（linear-PCA，τ = 6） | 斜率 2.19（SE 0.39），p = 1.9e-08 | 通过 |
| (iii) 阴性对照（打乱 D_GO） | 各模型 p 在 0.69 到 0.93 之间 | 通过 |

自检 (i) 中唯一落在带外的是划分 0 的均值模型，在主组合上：267 个测试单元覆盖了 226 个，参照带下限是 227。这是边际覆盖，期望值为 0.9；整个主组合 3 次划分合并的边际覆盖率为：均值 0.885，linear-PCA 0.889，linear-GO 0.889，linear-GO d = 2 0.888。
