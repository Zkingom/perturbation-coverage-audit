# GEARS 耦合检验方案 v1.0（冻结版，2026-10-19）

**证据等级：确认结果观察之后的新增分析（post-confirmation）。** 本方案不修改、不重定义、不覆盖 v0.7 的任何冻结配置、判据或结果；其结论不得作为确认性证据，也不得用于改变任何既有判定。用户已于 2026-10-19 确认；本版在 v0.1 草案基础上增加了第 5 节的准确度前提（修订记录见第 10 节），冻结哈希写入 `manifests/freeze_gears_coupling_v1.0.json`。

## 1. 要回答的问题

v0.7 的核心诊断是：在本文校准的线性预测器下，非一致性分数 S1 几乎是实测效应强度 E_true 的单调函数，因此按效应强度分层的覆盖率主要由分位数构造决定（round-2 第一步报告 §1–§2）。

**本检验只问一件事：一个表达能力更强的非线性模型（GEARS）是否降低这种耦合。** 不问 GEARS 的预测精度，也不把它作为新的确认集。

## 2. 固定不变的部分（与 v0.7 完全相同）

- 数据：RPE1 essential，`data/processed/v0.7/rpe1/`，与确认运行同一份 pseudobulk 与单元表。
- 划分：`splits/v0.7_conf/rpe1/` 的 21 个只读划分文件，不重新生成。
- 分数：S1（k = 50），参照 μ_tr、σ_g 与靶基因列排除规则与冻结实现一致，由 `models_v04.score_S1` 计算。
- 效应强度：E_true = 均值模型的 S1（`proxy_v06.e_true`），逐划分参照。
- 分层：同一五分位规则（`eval_v06.tiers_of`）。
- 校准：M0（split conformal，α = 0.1，`methods_v06.qhat`）。
- **GEARS 设定按 v0.6 第 10 节原样**：cell-gears 0.1.2，hidden_size 64，20 epochs，uncertainty 关闭，按验证集 top-20 DE MSE 选最优 epoch，**每个扰动训练数据上限 16 细胞**（固定种子），全部对照细胞。上传包与脚本已就绪（`gears_upload/gears_bundle_v07.tar.gz`，sha256 `9db14ae8e900…`）。

**不得更改的事项**：细胞上限、划分、分数定义、α、分层规则。若运行中发现必须偏离，停止并报告。

## 3. 主要量（pre-specified primary quantities）

对 GEARS 的测试集预测，按与 linear-PCA 完全相同的方式计算 S1，然后在 21 次划分合并后报告：

1. **CV(S1/E_true)** — 分数与效应强度之比的变异系数。
2. **残差份额 R** = 1 − R²(log S1 ~ log E_true)，即 log S1 中不被 log E_true 解释的方差份额。

参照值（v0.7 实测，`constructive_reference_by_model.csv`）：linear-PCA 在 RPE1 上 CV = 0.097、R = 0.065；linear-GO 为 0.116 / 0.094。

**CI**：按 TSS 组的聚类自助（2,000 次，种子 MASTER_SEED），与 `analysis_v06.cluster_boot` 同一实现。

## 4. 次要量

3. **T5 覆盖率**，以及它与解析参照的差：Δ = cov(T5) − 0.5，并同时给出均值模型在同一划分上的构造性参照（该参照已由冻结结果给出，为 0.4929）。
4. **边际覆盖率**（名义 0.9 带 [0.88, 0.92]）。
5. **相对均值模型的误差下降** 1 − mean(S1)/mean(E_true)，以及 T5、T1 内的同一量（v0.7 参照：RPE1 linear-PCA 整体 4.3%、T5 7.9%、T1 −3.4%）。
6. 描述性：Spearman(S1, E_true)、S1/E_true 的中位数与 5–95% 区间。

## 5. 判读规则（运行前写定）

设 R_GEARS 与 R_PCA 分别为 GEARS 与 linear-PCA 的残差份额（主要量 2），均在 RPE1、21 次划分上计算。

设 RER 为相对均值模型的误差下降 1 − mean(S1)/mean(E_true)，分别在全部测试单元与 T5 内计算；GEARS 与 linear-PCA 的差值按**同一划分、同一基因的配对比较**（两臂为同一组 (split, target) 行），CI 由按 TSS 组的聚类自助给出（2,000 次，两臂同步重抽样，种子 MASTER_SEED）。

- **准确度前提（2026-10-19 增加）**：RER_GEARS − RER_PCA ≥ 0，在**整体与 T5 上同时成立**（RPE1 的 linear-PCA 参照值为 4.3% 与 7.9%），判定以点估计为准，并一并报告配对差值的 95% CI。
- **"明显降低耦合"**：**准确度前提成立**，**且** R_GEARS ≥ 2 × R_PCA（即 ≥ 0.13），**且**该比值的自助 95% CI 下界 > 1.2，**且** CV(S1/E_true) 的点估计至少增加 50%。
- **"耦合指标上升伴随准确度下降，不能解释为解耦"**：R 或 CV 达到上述阈值，但准确度前提不成立（整体或 T5 的 RER 低于 linear-PCA）。
  增加这一前提的理由：R 与 CV 的提高有两条互斥的来源——模型捕捉到了与效应尺度无关的扰动特异信号（真正的解耦），或模型只是引入了与效应强度无关的额外误差（分数变噪，R 同样升高）。只看 R 与 CV 无法区分两者，必须同时要求准确度不下降。
- **"未降低耦合"**：R_GEARS / R_PCA 的 CI 上界 < 1.5。
- **"不确定"**：其余情形。

阈值的依据：R_PCA = 0.065 意味着约 93.5% 的 log 分数方差由效应尺度解释；只有当未解释份额翻倍以上，条件校准才可能有实质可利用的残差。该阈值是本方案提出的约定，不来自任何既有数据，**在看到 GEARS 结果之前写定**。

**阴性结果的表述方式（事先写定）**："在相同的划分、分数与细胞上限下，GEARS 的分数—效应强度耦合与线性基线无实质差异（R = 〈值〉 对 0.065，比值 CI 〈区间〉）。这说明该耦合不是线性模型特有的；但这是一次单一模型、单一数据集、单一分数的检验，不能推断对所有扰动预测模型成立。"

**"耦合指标上升伴随准确度下降"的表述方式（事先写定）**："GEARS 的未解释份额为 〈值〉（linear-PCA 0.065），但其相对均值模型的误差下降在整体为 〈值〉、在 T5 为 〈值〉，均低于 linear-PCA 的 4.3% 与 7.9%（配对差值 〈值〉 [CI]）。因此分数—效应强度耦合的下降伴随预测准确度的下降，更符合'分数中加入了与效应强度无关的误差'，不能解释为模型捕捉到了与尺度无关的扰动特异信号。"

**阳性结果的表述方式**："GEARS 将未解释份额提高到 〈值〉，相应地 T5 覆盖偏离构造性参照 〈值〉 个百分点。这表明耦合可以通过更强的模型降低，本文对线性预测器的诊断不能外推到所有模型。"

## 6. 必须一并报告的内容

- 覆盖率（T5、各层、边际）无论主要量结果如何都要报告，不得只报 CV / R。
- GEARS 在该设置下的预测误差（S1 的均值）与 linear-PCA 的对比，用于说明"更强的模型"这一前提是否成立：若 GEARS 的 S1 不低于 linear-PCA，则本检验只能说明"该模型未降低耦合"，不能说明"更强的模型未降低耦合"。这一限定必须写进结果段。
- 21 次划分中 GEARS 丢弃的扰动数（GO 图缺失、读出基因缺失），以及每次划分的训练时间与显存峰值。

## 7. 已知限制（写入结果段）

1. 训练数据每扰动上限 16 细胞，按原方案固定；GEARS 在更多细胞下表现可能不同。
2. 单一模型、单一数据集（RPE1）、单一分数定义。
3. 文献上 GEARS 在同类基准上未超过简单线性基线（Ahlmann-Eltze et al. 2025, doi:10.1038/s41592-025-02772-6），因此阴性结果是先验上更可能的结果；本检验的价值在于把这一点变成本文框架下的定量陈述，而不是宣称普遍性。
4. GEARS 的随机性：按参考实现固定 numpy 种子 1、torch 种子 0；GPU 非确定性未量化（如需，可在第 0 次划分上重复运行一次，属额外步骤）。

## 9. 运行前检查清单

1. 用户确认本方案并冻结（哈希写入 manifests）。
2. 服务器环境自检通过（`setup_gears_env.sh` 的 `SETUP PASS`）。
3. 单次划分冒烟测试通过，报告耗时与显存。
4. 全量 21 次划分在 tmux 或 nohup 下运行；断线后用 `tail -f logs/run_all.txt` 或 `tmux attach` 查看进度；重跑同一命令会跳过已校验划分。
5. 结果下载后在本机重新核对哈希，再计算主要量。
