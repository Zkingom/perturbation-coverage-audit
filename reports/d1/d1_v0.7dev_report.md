## 1. 第 4 阶段代码提速（已验证）

- **改动内容**：cluster bootstrap 原来每次重抽样都要用 `pd.concat` 拼接约 1,700 个小表，改成一次按行号 `take`。随机数的调用顺序、抽到的行和行的顺序都不变。第 4 阶段同时拆成独立函数 `summarise()`，计算内容没有变化。
- **验证结果**：
  - 单次划分：`summary.json` 改前改后**逐字节一致**；
  - 21 次划分：全部数值一致，只有 `m3_solver_fallbacks` 不同（5 对 0）。这是第 2 阶段累加的全局计数器，单独重跑第 4 阶段时不会执行到它；
  - 耗时从约 2.6 小时降到 111 秒。
- 本次重跑中，所有原有方法的 435 张分层表、名义 α 判据和宽度匹配判据与 D1 **逐项相同**。这说明新增方法没有改变任何原有结果。
- 改动记录在 `freeze_v0.6.2.json` 的 `post_freeze_code_fix_speedup` 字段。

## 2. 新基线的定义

- **(a) MD-GO / MD-STR**：按单元到模型拟合池的原始先验距离（D_GO 或 D_STRING）的五分位做 Mondrian 校准。五分位边界取自学习器单元的折外距离，与 M2、Mdist-M 的做法相同。只用先验信息，可以部署。
- **(b) Munc-N / Munc-M（"PRESCRIBE-like"，不声称复现 PRESCRIBE）**：
  - 对 linear-PCA 做 50 次 bootstrap 重拟合：按 TSS 组有放回重抽模型拟合池，K 取当次划分选定的值；
  - 代理定义为：在预测均值最大的 50 个基因（排除靶基因列）上，标准化预测值跨 bootstrap 方差的均方根；
  - 校准和测试单元用全部 50 次重拟合；学习器单元只用 OOB 重拟合，每个单元的 OOB 次数在 6 到 9 之间，没有少于 3 次的；
  - 两种用法：-N 是按代理归一化分数，-M 是按代理分层的 Mondrian；
  - 超参数按规则 7.2 选择。
- **最强基线的选择**：在 Mdist-N、Mdist-M、MD-GO、MD-STR、Munc-N、Munc-M 中，取宽度匹配后 T5 覆盖最高者，不设并列规则。结果是 **Mdist-M（B = 3）**。D1 当时在 M_dist 内部按 1 个百分点的并列规则选了更简单的 Mdist-N。

## 4. 解读（以审稿人标准）

1. **(a) 做到了它设计要做的事，但碰不到效应强度这条失效轴。**
   - MD-STR 把 D_STRING 五分位上的最大偏差从 0.080 降到 0.011；最近一档的覆盖从 0.820 升到 0.899，提高 +7.9 个百分点 [5.5, 10.3]。
   - 但它对 T5 没有改进：-0.2 [-3.8, 3.4]。MD-GO 同样没有改进。
   - 这是一个干净的**解离**：按距离分层的有效性可以修复，但修好之后，效应强度上的失效依然存在。
   - 原因：两种距离与 S1 只有弱的负相关（21 次划分平均 ρ：D_GO -0.13，D_STRING -0.19），与 E_true 的相关也弱（-0.22、-0.26）。负号表示：离训练扰动越近的扰动，效应反而越强。这与 D_STRING 最近一档欠覆盖的现象一致，也与第 5 节的度数结果一致。
2. **(b) 模型自身的 bootstrap 不确定性基本不含这条信息，Munc-N 甚至使 T5 变差（-6.4 [-10.1, -2.8]）。**
   - bootstrap 离散度与 S1 几乎不相关（平均 ρ = -0.04），与 E_true 也几乎不相关（0.06）。
   - 局限要说清楚：这只是"线性低秩模型的 bootstrap 方差"这一种不确定性，**不能推广为"PRESCRIBE 的不确定性无效"**。PRESCRIBE 的估计方式不同，它的不确定性也可能包含其他信息。论文中应写成"一种 PRESCRIBE-like 的模型不确定性代理"。
3. **ĥ 类方法相对最强基线有增量**：M1 − Mdist-M = +6.6 [3.4, 9.8]；决策场景下为 +6.8 [4.0, 9.5]。
4. **Mscore-N ≈ M1**（T5 分别为 0.647 和 0.639）。ŝ 直接拟合折外分数，用的是同一组特征，所以修复所用的信息来自特征本身，主要是先验邻居的效应。效应强度在这里的角色是**解释失效机制的变量**，并不是只有以它为目标才能修复。
5. **差距仍然很大**：oracle 的 T5 为 0.998；所有可部署方法的 T5 都 ≤ 0.647。按 v0.6 的绝对门槛（T5 ≥ 0.85），**开发集上没有任何方法达标**。
6. **代价**：宽度匹配后，M1 的最近 D_GO 档覆盖提高、最远档覆盖下降（最远档的差为 -3.1 [-5.0, -1.2]），T4 也从 1.000 降到 0.952。也就是说，覆盖是从其他层重新分配过来的，不是凭空增加的。

## 5. 功能富集（第 9 节；描述性，只用开发集）

- **注释版本**：
  - GO OBO 为 releases/2026-07-26；GOA human GAF 生成于 2026-05-21（取自 current 目录，**与 OBO 不是同一期**，偏离了方案要求的"同一发布日期"）；
  - Reactome 当前版（Last-Modified 2026-06-21）；
  - CORUM 当前版（human）。
  - 文件 SHA256 记录在 `annotation_manifest.json` 中，文件已设为只读。
- **背景与符号映射**：背景为 1,786 个 E 基因；直接匹配 1,738 个，按同义词匹配 46 个，有 2 个无法映射（PRPF4B、QARS）。
- **基因集规模**：
  - G1 核心集 93 个；
  - G1 扩展集 156 个（方案写"约 120"，以实际数为准）；
  - D1 T5 层 359 个；
  - D1 三轮都欠覆盖的 151 个。
- **主要发现：欠覆盖基因与强效应基因基本是同一批。**
  - G1 核心集的 93 个基因中，有 78 个也属于"E_true 最高的 93 个"对照集；三个欠覆盖基因集全部落在 D1 的 T5 层内。
  - 核心集和对照集的代表性富集条目几乎相同：RNA 3′ 端加工、核 RNA 降解、RNA 外切体（CORUM:788，8/10）、Pol II 转录和 TFIID。
  - T5 层富集的是 rRNA 加工、小亚基加工体、胞质核糖体（CORUM:306，44/74）和 RNA 代谢。
  - 所以，富集结果描述的是"强效应扰动"的功能特征，**没有证据表明欠覆盖基因是另外一类**。D1_T5 的对照集与它重叠 357/359 个基因，比较没有意义，这里只列出、不作解读。
- **检验你提出的推测（T5 与其他 E 基因比较）**：
  - **属于 CORUM 复合体的比例**：78% 对 64%，OR 1.96，p = 6.2e-07。所属复合体个数的中位数为 3 对 1。
  - **STRING 度数**（实验或数据库通道得分 ≥ 0.4）：筛选集内中位数 68 对 28；全基因组中位数 118 对 64，p = 4.1e-19。
  - **多变量 logistic**（T5 ~ CORUM 成员 + 筛选集内度数 + GO 注释数，各变量按 SD 标准化）：
    - 度数 +0.59 [0.44, 0.73]；
    - CORUM 成员 +0.10 [-0.04, 0.24]；
    - GO 注释数 +0.07 [-0.06, 0.19]。
  - **解读**：推测在边际层面成立。控制度数后，复合体成员身份不再有额外信息。但这不能说明"度数比复合体更本质"，原因有二：
    1. STRING 的 database 通道本身就收录了 CORUM 等复合体资源，两者高度共线；
    2. 研究得越多的基因，注释和互作记录越多（研究偏倚）。
  - 这一结果为 ĥ 中的邻居特征提供了生物学解释：处于高度连接模块中的扰动，自身效应强，邻居的效应也强。但它是描述性的，不能作为因果结论。
