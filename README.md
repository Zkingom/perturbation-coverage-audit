# Effect-stratified coverage audit of single-cell perturbation predictions

Code, frozen protocols, hash manifests, splits and result files for the manuscript
"A diagnostic for when effect-stratified coverage of single-cell perturbation predictions is informative"
(Xu Zhou, Independent Researcher; manuscript submitted to Genome Biology, 8 November 2026).

## Contents

| Folder | Content |
|---|---|
| `manuscript/` | Manuscript and Additional file 1 (Markdown sources of the submitted version), figures, Additional file 2 = Supplementary Table S7 (number-to-source map) |
| `reports/protocol/` | All analysis protocols, each frozen before the corresponding data were analysed |
| `manifests/` | Freeze manifests with SHA-256 hashes of protocol, code and data files |
| `code/` | Analysis code (Python; one R script for the GLMM); `code/paths.py` resolves all paths |
| `scripts/` | Constructive-reference Monte Carlo (`constructive_reference_mc.py`) |
| `splits/` | Read-only split files used by every analysis |
| `data/raw/` | Raw-data manifests (source URLs, checksums); raw data are not redistributed |
| `data/processed/` | Small processed tables (unit tables, gene lists, build records); large matrices are regenerated by the code |
| `results/` | Result summaries (JSON/CSV/text) cited in the manuscript; per-split caches are not included |
| `reports/review/`, `reports/paper/` | Derived tables used in the manuscript (constructive reference, subsets, CORUM, source maps) |
| `gears_server/` | GEARS run on a rented GPU host: bundle code, audit pack, logs and summary |

Every number in the manuscript is listed with its source file and field in `manuscript/AdditionalFile2_TableS7_number_source_map.csv`.

## Data

Raw data are public and are downloaded separately; file names and checksums are in `data/raw/*.json`:

- Replogle et al. 2022 Perturb-seq screens (K562 essential, RPE1, K562 genome-wide): Figshare+ doi:10.25452/figshare.plus.20029387.v1
- Norman et al. 2019 combinatorial screen, HepG2 and Jurkat screens of Nadig et al. 2025, Wessels et al. 2023: scPerturb, Zenodo record 13350497
- GO, STRING v12, Reactome and CORUM annotations: sources and SHA-256 in `manifests/freeze_v0.7.json`

## Reproducing

1. Python 3.11 with numpy 2.4.6, scipy 1.17.1, pandas 2.3.3, scikit-learn 1.9.1, statsmodels 0.15.0, h5py 3.16.0, anndata 0.12.19, python-igraph 1.0.0, leidenalg 0.12.0, pyarrow 25.0.0; R with lme4 and arrow for `code/g1_glmm_v05.R`. GEARS ran in a separate environment (`gears_server/gears_results_v07/gears_audit_v07/AUDIT/pip_freeze.txt`).
2. Set `download_root` in `config.toml` (or the environment variable `PERTAUDIT_DL`) to the folder holding the raw files. All other paths are relative to the folder containing `config.toml`.
3. Verify frozen files against the manifests (SHA-256) before running.
4. Run the stage scripts named in each protocol (for example `code/confirm_run_v07.py`, `code/norman_v12.py`, `code/norman_v13.py`, `code/nadig_v12.py`). Long stages write one result per split with a completion marker and can be resumed. Master seed: 20261001.

Memory: the pipeline was run on a 16 GB Windows machine with a 4 GB per-process cap, reading single-cell files in backed, chunked mode.
